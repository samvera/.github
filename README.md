# Samvera
This is a special repo for the Samvera community. 

The profile/README.md will appear on the organization's profile.

Issue templates in `samvera/.github/.github/ISSUE_TEMPLATE` (yes, `.github` goes twice) will be available for any Samvera organization repository that does not already have an issue template directory. 

See more about this type of special repository at [Creating a default community health file](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
